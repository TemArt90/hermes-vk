# hermes-vk — канал ВКонтакте для Hermes Agent

[![tests](https://github.com/TemArt90/hermes-vk/actions/workflows/tests.yml/badge.svg)](https://github.com/TemArt90/hermes-vk/actions/workflows/tests.yml)
[![license](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Плагин-адаптер, подключающий [Hermes Agent](https://hermes-agent.nousresearch.com/docs) к сообществу
ВКонтакте. Входящие сообщения — через **Bots Long Poll API**, исходящие — через `messages.send`.
Публичный адрес, домен и вебхук **не нужны**: Long Poll — это исходящее длинное соединение, поэтому
канал работает и там, где входящие подключения недоступны или режутся провайдером.

Реализация независимая, на Python, под контракт платформенных плагинов Hermes. Поток и форматы
(Long Poll, клавиатуры, `format_data`) разобраны по образцу плагина
[pfrankov/openclaw-vk](https://github.com/pfrankov/openclaw-vk) — см. [NOTICE](NOTICE).

> **English summary** — a VK (VKontakte) channel plugin for Hermes Agent. Inbound over the Bots
> Long Poll API (no public URL, no webhook), outbound over `messages.send`; markdown → VK
> `format_data`, inline callback keyboards for clarify/approval prompts, photo/document/voice
> uploads, pairing-based access control, cron delivery. Install by cloning into
> `~/.hermes/plugins/platforms/vk`, then `hermes plugins enable vk-platform`. Apache-2.0.

## Возможности

| Возможность | Как работает |
|---|---|
| Текст | `messages.send`, нарезка под лимит VK (4000 символов с запасом) |
| Разметка | Markdown → VK `format_data`: **жирный**, *курсив*, ссылки; офсеты в UTF-16 |
| Таблицы | VK их не умеет — конвертируются в «жирный заголовок + пункты»; код в ``` остаётся кодом |
| Цитаты | `> текст` → курсив; в беседе ответ уходит с цитатой входящего сообщения |
| Картинки и файлы | `photos`/`docs.getMessagesUploadServer`; подпись и вложение — одним сообщением |
| Голосовые | Ogg Opus через `ffmpeg`; если `ffmpeg` нет — файл уходит документом |
| Кнопки | inline-клавиатура + `message_event`: вопросы агента (clarify), подтверждение опасных команд, подтверждение слэш-команд |
| Входящие медиа | фото, документы и голосовые скачиваются в медиа-кэш агента (фото доступно vision) |
| Доступ | штатные гейты Hermes (`VK_ALLOWED_USERS` / `VK_ALLOW_ALL_USERS`) + pairing-код |
| Расписание | `deliver=vk`, в том числе в списке (`deliver=email,vk`) для cron-отчётов |
| Клавиатура команд | опционально (`VK_COMMAND_KEYBOARD=true`): кнопки `/help`, `/status`, `/new`, `/stop` над полем ввода — тап отправляет команду. Выключить: `VK_COMMAND_KEYBOARD=false` + рестарт |

Кнопки используют общую конвенцию Hermes (`cl:` / `ea:` / `sc:`), поэтому сценарии работают так же,
как в Telegram: нажатие подтверждает выбор, а не присылает текст; неавторизованный нажимающий
получает отказ; кнопка одноразовая.

## Установка

```bash
git clone https://github.com/TemArt90/hermes-vk ~/.hermes/plugins/platforms/vk
hermes plugins enable vk-platform
```

Затем `hermes gateway restart` — **в отдельном терминале**: изнутри работающего шлюза команда
блокируется самим шлюзом.

Требования: Hermes Agent (используется его Python-окружение; `aiohttp` там уже есть) и, только для
голосовых, `ffmpeg` в `PATH`. Своего веб-сервера, домена и сертификата не требуется.

## Настройка сообщества (действия человека в ВК)

1. Создайте **сообщество** (группу или публичную страницу).
2. `Управление` → `Сообщения` → включить сообщения.
3. `Управление` → `Работа с API` → `Ключи доступа` → **Создать ключ** с правами:
   - «Сообщения сообщества»;
   - «Управление сообществом» — без него **не работает Long Poll API**;
   - «Фотографии» и «Документы» — если нужны картинки и файлы в ответах.
4. `Управление` → `Работа с API` → `Long Poll API`: включить, в «Типах событий» отметить
   **«Входящие сообщения»** и **«Действие с сообщением»** — без второго кнопки-варианты будут
   «крутиться» без реакции.
5. Для ответов в беседах: `Управление` → `Сообщения` → `Настройки для бота` →
   «Разрешать добавлять сообщество в чаты».
6. Для кнопок: там же включить **«Чат-бот»** — иначе VK отвечает ошибкой 912 на любую клавиатуру,
   и адаптер вынужден деградировать до нумерованного текста.
7. Токен положить в `~/.hermes/.env` (в переписке токен не передаём и не принимаем):

```dotenv
VK_TOKEN=vk1.a.ваш_ключ
VK_HOME_CHANNEL=ваш_vk_id          # куда слать отчёты по расписанию
VK_ALLOWED_USERS=ваш_vk_id         # или оставить пустым и подтвердить pairing-кодом
```

## Конфигурация

| Переменная | Обязательна | Назначение |
|---|---|---|
| `VK_TOKEN` | да | Ключ доступа **сообщества** («Сообщения сообщества» + «Управление сообществом») |
| `VK_HOME_CHANNEL` | нет | peer id для доставки cron-отчётов (`deliver=vk`) |
| `VK_ALLOWED_USERS` | нет | Список VK id через запятую, кому разрешено писать боту |
| `VK_ALLOW_ALL_USERS` | нет | Разрешить всем (только для тестов) |
| `VK_QUOTE_IN_GROUPS` | нет | Цитировать входящее в беседах (по умолчанию `true`) |
| `VK_COMMAND_KEYBOARD` | нет | Клавиатура с командами над полем ввода (по умолчанию `false`) |
| `VK_API_VERSION` | нет | Версия VK API (по умолчанию `5.199`) |
| `VK_GROUP_ID` | нет | ID сообщества; обычно не нужен — `groups.getById` определяет его из токена |

id сообщества определять вручную не нужно: адаптер спрашивает его у VK по токену.

## Проверка

```bash
cd <hermes-install>                       # каталог Hermes, где лежит venv/

# канонический прогон (pytest не входит в runtime-venv Hermes)
venv/bin/pip install pytest               # аддитивно; pip check остаётся чистым
venv/bin/python -m pytest <plugin-dir> -q # 33 passed

# то же самое без pytest — каждый файл умеет самозапуск
PYTHONPATH=$PWD venv/bin/python <plugin-dir>/tests/test_vk_adapter.py
PYTHONPATH=$PWD venv/bin/python <plugin-dir>/tests/test_vk_live_loop.py
```

Пути разрешаются автоматически (`tests/_paths.py` находит runtime через `$HERMES_INSTALL`, стандартную
раскладку `~/.hermes/hermes-agent` или текущий каталог) и регистрирует каталог плагина как пакет `vk`,
поэтому запускать можно откуда угодно — в том числе из клона с дефисом в имени (`hermes-vk`), где имя
каталога не является допустимым именем модуля.

`test_vk_live_loop.py` поднимает на `127.0.0.1` мок VK API и Long Poll и проводит через настоящий
адаптер полный цикл `connect() → long poll → входящее → send() → disconnect()`, включая восстановление
после `failed=1` (сдвиг курсора) и `failed=2` (переподключение сессии) и повтор с тем же курсором при
транспортной ошибке. Настоящий токен и сеть ему не нужны.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| `groups.getLongPollServer` → ошибка 15/27 | у ключа нет права «Управление сообществом» либо Long Poll API выключен |
| Бот не видит сообщения | в Long Poll не отмечено «Входящие сообщения»; проверьте также, что шлюз перезапущен после правки `.env` |
| Сообщения приходят, ответов нет | отправитель не в `VK_ALLOWED_USERS` (либо ждёт подтверждения pairing-кодом) |
| Нажатие кнопки «крутится», в логе ошибка 912 | в сообществе не включён «Чат-бот» |
| Кнопка «крутится» бесконечно, в логе пусто | обрыв long poll: VK буферизует события ~5 минут и повторяет их для того же `ts`, но новый `getLongPollServer` отдаёт **текущую** позицию — переподключение сессии «перепрыгивает» накопленное. Адаптер при транспортной ошибке повторяет с тем же `ts`; в логе есть строки `message_event received` и предупреждение при неизвестном типе апдейта |
| `901 Can't send messages for users without permission` | сообщество не может писать первым: пользователь должен один раз написать ему сам. На «пустом» сообществе стартовое уведомление шлюза падает с 901 — это норма, не ошибка конфигурации |
| Разметка исчезла целиком | VK молча обнуляет весь `format_data`, если в нём есть неподдерживаемый тип. Адаптер отправляет только `bold`/`italic`/`url`; `~~strike~~` снимается до отправки |
| Ответ приходит с блоком «💭 Рассуждения» | выключите per-platform вывод: `display.platforms.vk.show_reasoning: false` |
| Плагин отключился после `hermes update`, в логе `uv lock exited 2` / `TOML parse error` | в каталоге плагина оказался `pyproject.toml`: менеджер плагинов принял его за сборку пакета. Файл удалить (конфиг тестов живёт в `pytest.ini`), затем `hermes plugins enable vk-platform`. От этого защищает `tests/test_plugin_layout.py` |
| `Platform 'VK' requirements not met` | пустой `VK_TOKEN` в `.env` профиля |
| `hermes send ... MEDIA:...` без текста | ядро разрешает медиа без подписи только для telegram/discord/matrix/… — добавьте короткую подпись рядом с `MEDIA:` |

## Как устроено

| Слой | Файл | Задача |
|---|---|---|
| Транспорт | `vk_api.py` | `groups.getById` → `groups.getLongPollServer` → `a_check` (wait=25, version=3); `messages.send`; ответ на нажатия; загрузка фото/документов/голосовых; разбор кодов ошибок VK с человеческими подсказками |
| Разметка | `vk_markdown.py` | Markdown → `format_data` (allowlist типов, офсеты в UTF-16, нарезка по лимиту); таблицы → пункты; цитаты → курсив; `to_plain` для кнопок и подписей |
| Адаптер | `adapter.py` | цикл Long Poll и восстановление, входящие события, кнопки, медиа, pairing, `deliver` для cron |
| Манифест | `plugin.yaml` | описание плагина и переменных окружения (используется `hermes plugins`) |
| Тесты | `tests/` | 32 проверки: логика рендера, дедупликация, кнопки, медиа, формат каталога, живой цикл на мок-сервере |

Полезные детали про VK, добытые на живом сообществе (коды ошибок, лимиты клавиатур, `format_data`,
логика курсора, причём именно то, что неочевидно из документации), собраны в
[docs/vk-api-notes.md](docs/vk-api-notes.md).

## Разработка

- Тесты запускаются через `pytest` (см. «Проверка») либо самозапуском — оба пути поддерживаются.
- `pytest.ini` намеренно, а **не** `pyproject.toml`: менеджер плагинов Hermes считает любой
  `pyproject.toml` в каталоге плагина сборкой пакета, копирует плагин в `plugin-sources/<key>/` и
  запускает `uv lock`; без `[project].name`/`version` это падает, и плагин отключается на следующем
  `hermes update`. Тест `tests/test_plugin_layout.py` следит, чтобы такой файл не появился.
- `filterwarnings = error` в `pytest.ini` (именно `error`, **не** `error::RuntimeWarning`): тест,
  вызывающий async-метод без `await`, создаёт корутину, которую никто не исполняет, и «проходит»
  вхолостую. Предупреждение приходит из деструктора, поэтому категорийный фильтр его не ловит —
  безусловный `error` ловит. Побочная польза: строгий режим сразу вскрывает незакрытые event loop.
- Проверяя тест, ломайте ровно ту ветку, которую он покрывает, в копии каталога: тест обязан упасть.
  Иначе легко проверить не то, что кажется.

## Ограничения

- Вложения кроме фото/документов/голосовых (опросы, истории, стикеры и т. п.) не обрабатываются.
- Видеозвонки и прямые трансляции VK вне области задачи.
- Исходящие голосовые требуют `ffmpeg`; без него отправляется документ.
