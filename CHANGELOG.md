# Changelog

## 1.0.1 — 2026-10-03

- Исправлено: команда с вложением (`/new` с фото, `/help` с пересланным сообщением) уходила в ядро
  вместе с пометкой вида `[фото]`, и хвост попадал в аргументы команды (имя сессии у `/new`,
  заголовок у `/title`). Пометка больше не примешивается к команде; файл приходит в `media_urls`.
- Исправлено: тесты не собирались при клоне репозитория в каталог с дефисом в имени
  (`hermes-vk`): pytest резолвил пакет чекаута через корневой `__init__.py` и импортировал его
  как модуль. Теперь `__init__.py` терпим только к импорту вне пакета (на пакетном пути ошибки
  по-прежнему всплывают), а `tests/_paths.py` регистрирует плагин как пакет `vk` и находит runtime.

## 1.0.0 — 2026-10-03

Первая публичная версия. Канал ВКонтакте для Hermes Agent: Bots Long Poll на вход,
`messages.send` на выход, без вебхука и домена.

**Что входит**

- Транспорт: `groups.getById` → `groups.getLongPollServer` → `a_check` (wait=25, version=3),
  восстановление после `failed=1/2/3`, повтор с тем же курсором при транспортной ошибке
  (иначе VK молча пропускает события, накопившиеся за время обрыва).
- Разметка: Markdown → `format_data` (`bold`/`italic`/ссылки) с офсетами в UTF-16,
  allowlist типов (одна неподдерживаемая конструкция обнуляет весь `format_data`),
  нарезка под лимит VK, таблицы → «заголовок + пункты», цитаты → курсив.
- Медиа: приём фото/документов/голосовых в кэш агента; отправка через
  `photos`/`docs.getMessagesUploadServer`; подпись и вложение одним сообщением;
  голосовые — Ogg Opus через ffmpeg с деградацией в документ.
- Кнопки: inline-клавиатура + `message_event`, общая конвенция Hermes
  (clarify / подтверждение опасных команд / слэш-подтверждения), обязательный ответ
  на нажатие, отказ неавторизованным, одноразовость кнопок.
- Доступ: штатные гейты Hermes + pairing-код, без собственной логики allowlist.
- Доставка по расписанию: `deliver=vk` (в том числе в списке `email,vk`).

**Проверено**

- 32 автотеста (`pytest`), включая живой цикл на мок-сервере VK: `connect → long poll →
  входящее → send → disconnect`, обрыв соединения и восстановление сессии.
- Живым сообществом: маршрут «входящее сообщение → сессия агента → ответ»,
  разметка на проводе (`format_data` через `messages.getHistory`), загрузка картинки
  с подписью одним сообщением, доставка крон-отчёта.

**Чего в этой версии нет**

- Голосовые исходящие проверены только при наличии `ffmpeg`; без него файл уходит документом.
- Работа с «историями», опросами и другими типами вложений VK не поддержана.
